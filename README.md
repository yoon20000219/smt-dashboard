# SMT 공정 품질관리 대시보드

AI-Hub Validation 이미지 559장을 촬영 시각순으로 공급하면, 최종 멀티모달 모델
(YOLO11n + FiLM, 이미지 + 그 이미지의 **실제 센서 5초값**, ONNX)이 **이미지마다 정상 / 불량 여부와 불량 유형을 즉시 판정**하고,
판정 결과와 센서값을 구간으로 집계한 **불량률 관리도 / 센서 관리도로 공정 경보**(주의, 경고)를 띄우는 현장 품질 검사 대시보드입니다.
좌측 메뉴는 "품질관리 시스템"(현장 관리자용)과 "총 관리 시스템"(총공정책임자용, Tableau 자리)입니다.

처음 실행하는 경우 **`실행_가이드.md`** 의 순서를 따라 하세요 (압축 해제, 가상환경, 패키지 설치, `streamlit run app.py`).

## 품질관리 시스템 화면

- **재생 제어**(시연용): 좌측 메뉴 아래에 시작 / 정지 / 처음 버튼, 본문 상단에 재생 간격(초/장), 재생 위치, 검출 신뢰도 임계값. 저장된 이미지를 순서대로 공급하는 장치이며 현장 연동 시 카메라/DB 입력으로 대체됩니다.
- 불량률 집계 구간(20건)과 허용 불량률(10%)은 `pages/01_품질관리_시스템.py` 상단의 `WIN_N`, `P0` 로 바꿉니다.
- **이미지 판정**(상단 배너): 불량 클래스 박스가 임계값 이상으로 1개라도 있으면 "불량 판정 / 유형", 없으면 "정상 판정". 불량 유형은 신뢰도가 가장 높은 불량 박스의 클래스입니다. 개별 판정은 이미지마다 독립입니다.
- **공정 경보 기준**: 불량률 관리도와 센서 관리도(경보 이력과 차트에 표시).
  - 불량률 관리도(p 관리도): 최근 N건 불량률이 허용 불량률을 넘으면 주의, 관리상한 `p0 + 3*sqrt(p0(1-p0)/N)` 을 넘으면 경고.
  - 센서 관리도: 5채널 평균의 마할라노비스 거리 D 가 단일점 한계를 넘으면 경고, EWMA(λ=0.2)가 관리상한을 넘으면 주의. 기준선은 정상 센서 데이터(`data/spc_baseline.json`).
- **검사 이미지 / 검출 내역 / 불량 유형 분포 / 측정 환경**: 현재 이미지의 박스, 현재 이미지의 불량 유형 분포(정상 이미지에서는 표시 안 함), 센서 5채널 값과 기준선 대비 편차.
- **추이 차트**: 불량률 관리도, 불량 유형별 누적 발생, 센서 이상도(D, EWMA), 채널별 기여도, 센서 5채널 추이(기준선 ±3σ).
- **이력**: 경보 이력(경보 수준이 올라간 시점), 검사 이력(최근 10건).
- **접이식 분석**: 누적 판정 성과(불량 검출률, 정상 오검출률, 정확도), 검사기준별 판정 유형.

## 이미지-센서 1:1 연결 방법

센서 원본(`A_센서데이터_원본.csv`)에는 파일명이 없어, 다음 규칙으로 복원했습니다 (`tools/build_stream.py`).

1. (공정, 정상/불량, 검사유형) 그룹 안에서 이미지 파일명을 촬영 카운터순으로 정렬한 순번 = 센서 데이터 같은 그룹의 event_id 순번.
2. 그룹별 Training/Validation 배치 패턴이 센서 데이터의 split 열과 완전히 일치하는 경우에만 채택(유일 후보일 때만).
3. 공유 패키지 sample 20장 중 매핑 가능한 19장은 센서 원본 25개 값이 소수점까지 일치.
4. 대시보드에 쓰는 559장은 모두 Validation 이며 정답 라벨(y)도 100% 일치.

## 스트림 데이터 만들기 (다른 이미지로 바꾸고 싶을 때)

```bash
python tools/build_stream.py --zips <Validation/01.원천데이터> --pkg <SMT_final_model_share> --sensor_csv <A_센서데이터_원본.csv>
```

`data/stream_sequence.csv`, `data/predictions.json`, `data/stream_meta.json` 을 다시 만듭니다.

## 알아둘 점

- 559장은 3개 세션(정상-납부족, 불량-납부족, 불량-납볼)이며, 정답 라벨은 정상/불량과 파일명의 검사기준 코드까지만 있어 유형 정확도는 산출하지 않고 판정 유형 분포로만 보여줍니다. 박스별 정답은 AI-Hub 라벨링 JSON에 있습니다.
- 이미지마다 서로 다른 기판·부위를 촬영한 것이라 개별 판정은 이미지 단위로 독립입니다. 공정 경보는 판정 결과의 집계(불량률)와 센서 관리도로 판단합니다.
- 센서 관리도의 이탈은 불량 이미지 세션에서 크게 나타나지만, 세션별 수집 환경 차이가 섞여 있을 수 있어 인과로 해석하지 않습니다.
- 테스트셋이 준비되면 `tools/build_stream.py` 로 `data/` 의 CSV·JSON·이미지를 교체해 같은 화면으로 검사할 수 있습니다.
- 검출 신뢰도 기본값은 0.25 입니다. 낮추면 미검출이 줄고 오검출이 늘어납니다.
